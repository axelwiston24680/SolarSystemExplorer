# Solar System Explorer 🌌

A playful Android learning app for children ages 6–9. Explore the Sun and eight planets, learn a few facts, and take a short quiz.

## Features
- Colorful, cartoon-style solar system illustration with tappable planets.
- Short, child-friendly facts for every planet.
- Planet detail cards and a five-question quiz.
- Java and XML; no account, network access, or external assets required.

## Build
Open this project in Android Studio, allow Gradle sync, then choose **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

Or push/commit the project to GitHub: the workflow in `.github/workflows/android.yml` builds a debug APK automatically. Download it from the completed workflow run's **Artifacts** section.

**Package:** `com.axelwiston.solarsystemexplorer`
